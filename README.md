# Elektromērījumu atskaites

iPhone un datora pārlūkā lietojama PWA elektromērījumu datu ievadei un PDF vai DOCX atskaišu sagatavošanai.

## Lietošana iPhone

1. Atver GitHub Pages adresi Safari.
2. Izvēlies **Share → Add to Home Screen**.
3. Pirmajā lietošanas reizē atver lietotni ar internetu, lai saglabātu visus failus darbam bezsaistē.
4. Sertifikātus pievieno kā attēlus vienu reizi. Dati un attēli tiek glabāti tikai konkrētajā ierīcē.

## Iespējas

- objekta, pasūtītāja, darba veicēja un mēraparātu dati;
- izvēlamas mērījumu sadaļas;
- stāvu, telpu un ierīču hierarhija;
- vienfāzes un trīsfāžu īsslēguma strāvas un cilpas pretestības lauki;
- izolācijas, zemējuma nepārtrauktības, kontūra un zibensaizsardzības mērījumi;
- sertifikātu, termogrāfisko, parasto un shēmu attēlu pievienošana;
- PDF drukas skats, īsts DOCX fails un JSON rezerves kopija;
- automātiska saglabāšana ierīces IndexedDB un darbs bezsaistē.
